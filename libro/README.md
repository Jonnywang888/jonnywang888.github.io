# 📚 中意双语阅读网站

一个基于 PWA 的中意双语阅读网站，支持多用户、多章节、多设备同步阅读进度。

## ✨ 功能特性

### 🏠 首页功能
- **用户选择**: 支持爸爸、妈妈、小朋友三个用户角色
- **书籍选择**: 从 JSON 配置的书籍列表中选择
- **章节选择**: 选择具体章节开始阅读
- **进度记忆**: 自动跳转到上次阅读的书籍和章节

### 📖 阅读功能
- **双语显示**: 意大利语原文 + 中文翻译
- **翻译控制**: 
  - 默认仅显示意大利语
  - 每段可单独显示/隐藏翻译
  - 全局显示/隐藏所有翻译
- **章节导航**: 支持上一章/下一章切换
- **阅读设置**: 字体大小、行距、夜间模式
- **进度保存**: 自动记录阅读位置

### ⚙️ 技术特性
- **PWA 支持**: 可安装为桌面/移动应用
- **离线缓存**: 支持离线阅读
- **本地存储**: 无需数据库，所有数据本地保存
- **响应式设计**: 适配手机和桌面端
- **键盘快捷键**: 
  - `ESC`: 返回首页
  - `T`: 切换翻译显示
  - `D`: 切换夜间模式
  - `←`: 上一章
  - `→`: 下一章

## 🚀 快速开始

### 1. 启动本地服务器

由于需要加载 JSON 文件，请使用本地服务器运行：

```bash
# 使用 Python (如果已安装)
python -m http.server 8000

# 或使用 Node.js (如果已安装)
npx http-server

# 或使用 Live Server (VS Code 扩展)
```

### 2. 访问应用

打开浏览器访问 `http://localhost:8000`

### 3. 安装为 PWA

在支持的浏览器中，会提示安装应用，或点击地址栏的安装图标。

## 🎨 自定义样式

### 修改主题色
在 `styles/main.css` 中修改 CSS 变量：
```css
:root {
  --primary-color: #4A90E2;
  --secondary-color: #357ABD;
}
```

### 添加新字体
在 `index.html` 中添加 Google Fonts 链接，然后在 CSS 中使用。

## 📱 PWA 功能

### 安装提示
应用支持 PWA 安装，在支持的浏览器中会显示安装提示。

### 离线缓存
服务工作者会自动缓存应用资源，支持离线使用。

### 更新机制
当有新版本时，服务工作者会自动更新缓存。

## 🔧 开发说明

### 添加新书籍
1. 编辑 `data/books.json`
2. 按照现有格式添加书籍和章节数据
3. 刷新页面即可看到新书籍

### 添加新用户
1. 编辑 `data/users.json`
2. 添加新用户配置
3. 刷新页面即可看到新用户

### 修改样式
- 全局样式: `styles/main.css`
- 首页样式: `styles/home.css`
- 阅读页面样式: `styles/reader.css`

## 🌟 使用技巧

1. **学习模式**: 先隐藏翻译，尝试理解意大利语，再显示翻译对比
2. **复习模式**: 显示所有翻译，快速浏览内容
3. **多用户**: 家庭成员可以独立保存阅读进度
4. **章节导航**: 使用左右箭头键或按钮切换章节
5. **离线使用**: 安装为 PWA 后支持离线阅读
